# AFK on ReadyUp

Plugin SourceMod para Left 4 Dead 2 que mueve a espectador a los jugadores inactivos durante readyup. Puede expulsarlos si siguen en espectador después del tiempo de gracia.

## Instalación

1. Instala SourceMod y un plugin de readyup compatible.
2. Descarga el ZIP de [GitHub Releases](https://github.com/AoC-Gamers/AFK-on-readyup/releases) y extráelo en la carpeta `left4dead2/` del servidor.
3. Carga el plugin o reinicia el servidor. SourceMod genera `cfg/sourcemod/AFKReadyup.cfg` al cargarlo.

Consulta la [documentación](docs/README.md) o el [historial de cambios](CHANGELOG.md).
